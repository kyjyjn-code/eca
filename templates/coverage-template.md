# 커버리지 기록 규약 (`YYYY-MM.coverage.json`)

리서처는 회차마다 `data/raw/YYYY-MM.coverage.json` **하나**를 쓴다.
사람이 읽는 `YYYY-MM.coverage.md` 는 `scripts/check-coverage.js` 가 검증을 통과한 뒤 **자동으로 렌더**한다.
**md 를 직접 쓰지 않는다** — 두 파일을 각각 쓰면 서로 어긋나고, 기계는 어느 쪽이 맞는지 알 수 없다.

이 기록이 없으면 "무엇을 검토했고 무엇을 왜 버렸는지"가 남지 않는다.
2026-08 회차에서 신규 발굴이 0건이었는데 **원인을 밝힐 수 없었던 이유**가 정확히 이것이다.

---

## 열거값 (이 목록 밖의 값은 기계가 막는다)

회차마다 `YYYY-MM.targets.json` 의 `기록규약` 블록에도 같은 목록이 실려 온다.

| 필드 | 허용값 |
|---|---|
| `타깃처리[].결과` | `수록` · `배제` · `시즌아님` · `확인불가` |
| `탈락필터` (타깃처리·배제후보 공용) | `주최성` · `지원자격` · `학교단위접수` · `규모·역사` · `상업성` · `출처` · `만료` · `중복` |
| `타깃처리[].포스터` | `있음` · `없음` |
| 근거_원문 끝의 확인수준 | `요강원문` · `공고요약` · `연도불명` |

> **`배제-학교단위접수` 는 한 칸이 아니라 두 칸이다** — `결과: "배제"` + `탈락필터: "학교단위접수"`.
> 이렇게 나눠야 ① 필터별 배제 건수 집계가 깨끗하고 ② 쿼리로 발굴돼 targets 에 없는 학교접수 대회도
> `배제후보` 쪽에서 같은 기준으로 검토 큐에 잡힌다. md 로 렌더될 때는 `배제-학교단위접수` 로 되돌려 적힌다.

## 필수 규칙 — 어기면 파이프라인이 1.5단계에서 멈춘다

| # | 규칙 | 왜 |
|---|---|---|
| ① | `coverage.json` 이 존재해야 한다 | 기록 없는 회차를 만들지 않는다 |
| ② | **targets 의 모든 항목**이 `targets_id` 로 되돌아와야 한다 | 처리했는지 안 했는지를 이름이 아니라 키로 대조한다 |
| ③ | 신규 수록이 0건이면 `신규0건_사유` 를 반드시 적는다 | 0건 자체가 이상 신호다. 무엇을 확인했고 왜 없었는지 남긴다 |
| ④ | `data/raw/YYYY-MM.json` 의 **모든** 항목의 `근거_원문` 끝에 `[확인수준: …]` 을 붙인다 | 표기 부재 = 규칙 위반으로 기계가 판정한다. 최고 신뢰 등급이어도 생략하지 않는다 |
| ⑤ | `소스관찰.요약` 과 `시즌점검.요약` 은 빈 문자열이면 안 된다 | 특이사항이 없으면 **"특이사항 없음"** 이라고 적는다. 빈칸과 미작성을 구분하기 위해서다 |
| ⑥ | 열거값을 지킨다 | 값이 흔들리면 지표가 조용히 틀린다 |

`targets_id` 는 `make-targets.js` 가 부여한 것을 **그대로** 되돌려 준다. 임의로 만들지 않는다.

## 기록 요령

- **`배제후보`는 버린 것도 남기는 자리다.** 발굴했지만 3층 필터에서 탈락한 후보를 탈락 필터명·근거·출처 도메인과 함께 적는다. 같은 후보를 다음 달에 다시 평가하지 않기 위한 기록이다.
- **`출처도메인`은 도메인만** 적는다(`kofac.re.kr`). 전체 URL 이 아니다. 회고가 "어느 도메인이 실제로 수확을 내는가"를 집계한다.
- **`소스관찰`은 기록만 하는 자리다.** 좋아 보이는 허브를 만나도 `sources.json` 에 직접 추가하지 않는다. 소스의 추가·제거는 회고 제안과 사람 승인을 거친다.
- **포스터**: 수록하는 활동마다 공식 페이지에서 포스터·배너 이미지를 1회 탐색하고, 없으면 `"없음"` 으로 기록한다.

## 렌더 결과 (사람이 읽는 `coverage.md`)

검증을 통과하면 아래 구조로 자동 생성된다.

```
① 타깃 처리 결과      표: 대상 · 이름 · 처리 결과 · 수록 id/사유 · 포스터
② 쿼리 실행 로그      표: 쿼리 · 실행 · 후보 수 · 발견 출처 도메인
③ 순회 소스 방문 로그  표: 소스 · 방문 · 발견 수
④ 배제 후보 기록      표: 활동명 · 탈락 필터 · 근거 · 출처 도메인
⑤ 시즌 점검
⑥ 신규 0건 사유
⑦ 소스 관찰 로그
   (총평이 있으면 이어서)
```

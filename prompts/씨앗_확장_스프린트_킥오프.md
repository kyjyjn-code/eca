# 씨앗 확장 스프린트 — 킥오프 프롬프트

> **실행 전제:** 「ECA 시스템 개선 작업지시서」가 구현·머지된 뒤, 월간 파이프라인과 별도의 세션에서 1회성으로 실행한다. (씨앗의 canonical_slug·유형·예상_공고월 필드 체계 위에서 작업해야 하기 때문.)
> **승인자:** 담당자 / **목적:** 씨앗 46개 → 80~100개 확충

---

## 0. 배경과 목적

현재 씨앗 46개는 카테고리 편중이 있다 — 영어·경제·비즈니스·선발형 여름 프로그램·연구논문·아트 계열이 얇다. 이 스프린트는 월간 발굴과 별개로, 씨앗 목록 자체를 한 번에 확충한다. 시작 전에 `CLAUDE.md`와 `data/sources.json`을 숙지한다.

## 1. 씨앗의 정의 — 무엇이 씨앗이 되는가

- **매년·정기 반복 개최**되거나 **상시 운영**되는 활동만 씨앗이 된다. 1회성 공모는 씨앗이 아니라 월간 발굴 대상이다.
- 3층 검증 필터를 전부 충족해야 한다: 주최 공신력(정부·부처·공공기관·학회·대학·국제 공인단체) / 한국 거주·검정고시·대안경로 학생의 지원 가능성(근거 원문 확인) / 규모·역사 / 상업성 배제 / 공식 URL 존재.
- **개인 접수 가능이 원칙.** 학교 단위 접수만 가능한 활동은 씨앗으로 채택하지 않고 기관 접수 검토 큐 후보로 스프린트 리포트에 기록한다(파이프라인의 "배제-학교단위접수" 처리와 동일한 논리).

## 2. 목표 규모 — 참고치이며, 채우기 위한 기준 완화를 금지한다

| 카테고리 | 현재 | 참고 목표 |
|---|---|---|
| 과학·공학·수학생명·AI | 15 | 20 |
| 글쓰기·논문·인문사회 | 6 | 12 |
| 영어 | 6 | 10 |
| 국제·리더십·사회참여 | 5 | 8 |
| 환경·예술·공익 (아트·디자인 포함) | 4 | 8 |
| 스포츠·문화·봉사 | 4 | 6 |
| 경제·비즈니스 | 3 | 8 |
| 선발형 여름 프로그램 | 3 | 10 |
| **합계** | **46** | **82±** |

목표 미달은 실패가 아니다 — 카테고리별 사유를 리포트에 기록하는 것으로 갈음한다. 근거 없는 씨앗 1개가 미달 1개보다 나쁘다.

## 3. 우선 탐색 방향

아래 예시 명칭·방향은 **검증 대상 후보일 뿐이다.** 전 항목 공식 페이지의 최신 요강을 확인하기 전에는 채택하지 않는다.

- **선발형 여름 프로그램 (영문):** 해외 대학·연구기관의 pre-college / 청소년 연구 프로그램. 관건은 국제 학생(비거주·홈스쿨·대안경로) 지원 가능 여부 — eligibility 원문 확인 필수. 고액 상업형 "리서치 멘토링" 상품류는 배제.
- **국내 연구·논문:** 삼성휴먼테크 논문대상 고등부 등 (요강·부문 확인 필요).
- **영어:** 국제 에세이·디베이트·스피치 대회 중 개인 참가 가능한 것 위주.
- **경제·비즈니스:** 국내외 청소년 경제·창업·투자 대회.
- **통계·데이터:** 국내외 청소년 데이터 분석·통계 탐구 대회 (내부적으로 이미 검토된 방향).
- **아트·디자인:** 미대 트랙 학생용 국내외 공모 (환경·예술·공익 분류 하위로 편입).
- **국제 저널리즘·글쓰기:** 청소년 대상 공모 시리즈(예: The New York Times Learning Network 학생 공모 — 참가 연령·국제 참가 자격 확인 필요).

## 4. 방법

1. 카테고리별 쿼리 세트를 작성한다 — 국문+영문, 자격 관점 문구("open to international students", "homeschooled eligible" 등) 포함. 사용한 쿼리 전부를 리포트에 기록한다.
2. 기존 순회 소스·서브그리게이터에 더해, 해외 허브(대학 프로그램 목록 페이지, 대회 공식 파트너·계열 페이지)를 순회한다.
3. 후보마다: 공식 페이지 확인 → 지원자격 근거 원문 기록 → `[확인수준: …]` 표기 → 3층 필터 판정 → 접수 경로(개인/학교단위) 확인.
4. 채택 씨앗은 sources.json 형식으로 등록한다: `canonical_slug`, `유형(회차형|상시형)`, `예상_공고월`(불명 시 null + 확인필요), 분류.
5. 신규 씨앗의 공고·마감 시기를 시즌 캘린더에도 반영한다.

## 5. 산출물

1. `data/sources.json` 씨앗 추가 (PR로 제출).
2. 스프린트 리포트 `data/retro/seed-sprint-YYYY-MM.md`: 카테고리별 검토 후보 **전수**(채택 / 미채택+탈락 필터·사유 / 기관접수검토 큐행), 사용 쿼리 목록, 참고 목표 대비 결과와 미달 사유.
3. 기관 접수 검토 큐 후보 목록 (해당 시, `data/review/기관접수검토.md`에 update-review-queue 형식으로 추가 제안).

## 6. 진행 방식

- 카테고리 하나를 마칠 때마다 결과 요약(채택 수 / 검토 수 / 특이사항)을 보고하고 계속 진행한다. 승인 대기는 없지만, 판단이 갈리는 항목(공신력 애매·자격 모호)은 멈추고 질문한다.
- 최종 PR의 pr-body에 카테고리별 요약 표를 실어 사람이 일괄 검토·머지한다.

## 7. 하드 룰

- 근거 원문 없으면 미채택. 참가비만 비싸고 주최 공신력이 불분명하면 배제. 유료 사설 멘토링·컨설팅 상품류 배제.
- 결과 보장성 표현 금지, 금칙 명칭 3종 금지 — 저장소 가드레일과 동일 기준.
- 목표 수는 참고치다. 미달은 실패가 아니고, **기준 완화가 실패다.**
